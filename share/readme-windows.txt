OpenCode 语音输入 — 安装说明(Windows)
=====================================

【安装】
1. 双击 安装.bat。
   (如果 OpenCode 装在 Program Files,会自动弹出管理员权限请求,点"是")
2. 等待出现"安装完成!"(首次约 1~3 分钟,需复制约 300MB 数据)。
3. 打开 OpenCode:点击输入框右下角的麦克风图标,或按快捷键 Ctrl+Alt+Space,
   对着麦克风说话,说完停顿约 1.6 秒,文字会自动识别并填入输入框;
   再点一次麦克风或按快捷键可提前结束。

【安装位置】
默认把语音组件放在 OpenCode 自己的文件夹里:
    <OpenCode 文件夹>\voice-data
例如 D:\opencode\@opencode-aidesktop\voice-data
卸载时也只需清理这一个文件夹,其他盘不会留下大文件。

注意:语音引擎不支持中文路径。如果你的 OpenCode 安装路径或 Windows
用户名含中文,组件会自动改放到 C:\ProgramData\OpenCodeVoice。

想手动指定位置(纯英文路径),在本文件夹空白处按住 Shift 右键 →
"在此处打开命令窗口",运行:
    安装.bat -StableDir "D:\OpenCodeVoice"

【找不到 OpenCode?】
安装器会自动搜索注册表、常见安装位置以及正在运行的 OpenCode。
如果没找到,把 OpenCode 的安装文件夹(里面应有 OpenCode.exe 和
resources 文件夹)直接拖进本窗口后按回车即可。

【OpenCode 更新后麦克风没了怎么办?】
不用管。安装时启用了"更新监视":只有当 OpenCode 更新(替换 app.asar)
时才会自动重新打补丁,平时不运行、也不弹窗,更不会主动关闭 OpenCode。
更新完成后重新打开 OpenCode 即可,语音功能会保持。
从旧版本(v1.0.x)升级时,重新运行一次 安装.bat 即可拿到修复。

【卸载】
双击 卸载.bat:恢复原始 OpenCode,并删除自动修复任务与语音组件。

【常见问题】
- 提示"Windows 已保护你的电脑":点"更多信息"→"仍要运行"
  (脚本未签名,属正常提示)。
- 首次使用没声音:请在 系统设置→隐私 中允许桌面应用使用麦克风。
- 所有识别均在本机完成,不会上传任何语音数据。
- 想改快捷键:编辑数据目录下的 config.json 里的 hotkey,然后重启 OpenCode。
- 识别一直失败(卡在"识别中…"):多半是数据目录路径含中文/特殊字符,
  请用 -StableDir 参数换到纯英文目录后重新安装。
- 点了图标没反应 / 关窗口后再也打不开:这是 v1.1.0 之前版本的已知问题
  (语音悬浮窗残留占住单实例锁)。先在任务管理器结束所有 OpenCode 进程,
  然后重跑本安装包升级到 v1.1.0 即可彻底解决。
